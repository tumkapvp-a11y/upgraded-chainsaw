# AppleSub

Плагин подписки для **Paper 1.21.11** (Java 21). Подписка выдаётся командой `/applesub give`, после этого игроку открывается меню `/sub` с функциями. Оформление выдержано в красно-розовой гамме, данные хранятся в SQLite или MySQL/MariaDB.

## Функции меню `/sub`

| Функция | Что делает |
|---|---|
| **Ночное зрение** | Бесконечный эффект. Возвращается после смерти, молока и `/effect clear` |
| **Анти-огонь** | Скрывает огонь на экране горящего игрока. Урон от огня остаётся, другие игроки по-прежнему видят огонь |
| **Анти-мусор** | Игрок не подбирает мусор. К стандартному списку из конфига можно добавить свои предметы: ПКМ по воронке → клик по предмету в инвентаре. Клик по своему предмету в списке удаляет его |
| **Уведомления о броне** | Когда прочность надетой брони падает до порога (по умолчанию 15 %), приходит сообщение и титр со звуком наковальни. Отдельное уведомление приходит, когда броня ломается |

ЛКМ по иконке или по красителю под ней переключает функцию. Состояние каждой функции сохраняется в базе отдельно для каждого игрока.

## Команды

| Команда | Право | Описание |
|---|---|---|
| `/sub` | — | Меню подписки (только при активной подписке) |
| `/applesub give <ник> [срок]` | `applesub.admin` | Выдать или продлить подписку. Работает и для офлайн-игроков |
| `/applesub take <ник>` | `applesub.admin` | Забрать подписку |
| `/applesub check <ник>` | `applesub.admin` | Сколько осталось |
| `/applesub reload` | `applesub.admin` | Перезагрузить `config.yml` |

Алиас: `/asub`. Если срок не указан, берётся `subscription.default-duration`.

Формат срока: `30d`, `12h`, `1d12h`, `90m`, `1w`, `1mo`, `1y`, `forever`. Число без единицы считается днями. Можно писать и по-русски: `30д`, `12ч`, `навсегда`. Повторная выдача добавляет время к текущему сроку.

## Хранилище

```yaml
storage:
  type: sqlite   # или mysql
```

- **SQLite**: файл `plugins/AppleSub/database.db`.
- **MySQL / MariaDB**: заполните секцию `storage.mysql`. Таблицы создаются автоматически: `applesub_players` и `applesub_trash`, префикс задаётся в `table-prefix`.

Драйверы SQLite и MySQL уже входят в Paper. Пул соединений HikariCP Paper скачивает сам при первом запуске (секция `libraries` в `plugin.yml`), поэтому серверу нужен доступ к Maven Central.

## Сборка

```bash
mvn package
```

Готовый файл: `target/AppleSub-1.0.0.jar`. Положите его в `plugins/`.

## Настройка

Все тексты, меню, звуки, стандартный список мусора, порог прочности и значения функций по умолчанию задаются в `config.yml`. Тексты пишутся в формате [MiniMessage](https://docs.advntr.dev/minimessage/format).
