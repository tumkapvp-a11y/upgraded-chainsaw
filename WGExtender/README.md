# WGExtender 4.0.0 (Paper 1.21.11)

Переписанный под Paper 1.21.11 форк WGExtender 3.1.1-fork: расширяет WorldGuard защитой регионов,
лимитами `/rg claim`, автофлагами, запретом команд, режимами PvP и флагами old-PvP.

## Требования

- Paper 1.21.11, Java 21+
- WorldGuard 7.0.16+ и WorldEdit 7.3.18+ (проверено с WG 7.0.16 + WE 7.3.18 на Java 21
  и с WG 7.0.17 + WE 7.4.6 на Java 25)
- Vault — необязателен, нужен только для лимитов по группам (`claim.blocklimits.limits`)

## Сборка

```bash
cd WGExtender
mvn package
```

Готовый плагин: `target/WGExtender-4.0.0.jar`.

## Совместимость с 3.x

`config.yml`, команды (`/wgex`, право `wgextender.admin`) и флаги (`chorus-fruit-use`,
`oldpvp-attackspeed`, `oldpvp-nobow`, `oldpvp-noshieldblock`) не изменились — старый конфиг
и регионы подхватываются как есть. Палки `//wand`, выданные 3.x, тоже распознаются.

## Что изменилось

Оптимизация:
- Обработчики выключенных функций вообще не регистрируются (включаются/выключаются по `/wgex reload`),
  поэтому `BlockFromToEvent`, взрывы и т.п. ничего не стоят, если функция выключена.
- `oldpvp-attackspeed`: вместо проверки региона для каждого игрока каждый тик используется
  session handler WorldGuard (срабатывает при смене региона + раз в секунду на уже посчитанном наборе регионов).
  Скорость атаки меняется transient-модификатором, а не базовым значением — после краша сервера у игроков
  не остаётся скорость 16.
- Жидкости/огонь/горение: поиск регионов идёт напрямую по индексу WorldGuard, без лишних обёрток;
  огонь делает 2 поиска вместо 4; раздатчик больше не делает снимок `getState()` на каждый выброс.
- Взрывы: один запрос по области взрыва; если в ней нет регионов, поблочная проверка пропускается.
- `restrictcommands`: убрана асинхронная задача, читавшая карту команд из другого потока;
  сначала сравнивается строка команды, проверка региона — только для запрещённых команд.
- Режим `misc.pvpmode: default` больше не подменяет обработчик WorldGuard — работает родная логика WG.
- `/wgex removeowner|removemember` не блокирует основной поток поиском профиля игрока.

Исправления:
- `/wgex removeowner` перезаписывал список участников региона списком владельцев.
- `restrictcommands`: через ~5 секунд после старта команды без аргументов (`home`) переставали блокироваться.
- Лимит минимальной ширины сообщал «минимальный объём».
- PvP-обработчик синхронизирован с WorldGuard 7.0.16: урон от не-игроков снова проверяется WorldGuard
  (раньше игнорировался), учтены флаг `destroy-vehicle`, NPC и `use-paper-entity-origin`.
- `/rg claim` учитывает `regions.set-parent-on-claim` из конфига WorldGuard.
- Подмена `/rg` и `//wand` сохраняет автодополнение и права оригинальной команды
  и перехватывает все алиасы (включая `worldguard:region`).
- `wgex setflag` из консоли падал (прокси без интерфейсов `Actor`); теперь работает и не спамит сообщением на каждый регион.
- Без Vault лимиты больше не роняют `/rg claim` (применяется лимит `default`, если он задан).
- Ошибка подмены одной функции больше не выключает весь сервер — функция просто отключается с ошибкой в логе.
- Автофлаги при `/rg claim` ставятся без вывода сообщений WorldGuard игроку.
- Флаги регистрируются штатно в `onLoad` (рефлексия — только при горячей загрузке плагина).
